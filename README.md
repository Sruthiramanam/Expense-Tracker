# Expense Tracker 💰

## About the Project
Expense Tracker is a simple web application built with HTML, CSS, and JavaScript that helps users manage their income and expenses. Users can add transactions, view their balance, track income and expenses, and delete transactions. The app saves transaction data in the browser using Local Storage.

## Features
- Add income and expense transactions
- View total balance
- Track total income and expenses separately
- Delete individual transactions
- Validate transaction descriptions and amounts
- Automatically update totals when transactions change
- Save transactions using browser Local Storage
- Responsive layout for smaller screens

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a transaction description and amount.
5. Use positive amounts for income and negative amounts for expenses.
6. View your balance and transaction history.
7. Delete transactions whenever needed.

## How It Works
- **Add Transactions:** Enter a description and amount to record income or expenses.
- **Balance Calculation:** The balance is calculated by adding all transaction amounts.
- **Income and Expenses:** Income and expense totals are displayed separately.
- **Delete Transactions:** Remove transactions from the history.
- **Local Storage:** Transaction data remains saved when the page is refreshed in the same browser.

## Currency
The application currently displays amounts in US dollars ($).

## Limitations
This is a front-end project. Transaction data is stored locally in the browser and is not synchronized across devices or users.
